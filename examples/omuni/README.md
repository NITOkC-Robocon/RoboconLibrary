# omuni.cpp

##　概要
4輪オムニの操縦コード

##　配線
PC用のピン
TX = PA_2
RX = PA_3

コントローラ通信用のピン
TX = PC_12
RX = PD_2

PWM出力のピン
PC_9, PA_9, PB_6, PC_7（基盤の　J1～J4　に対応）

DIR出力ピン
PB_8, PC_0, PA_7, PC_5（基盤の　J1～J4　に対応）

##　動作
PS3コントローラからのデータに応じて足回りを操縦（最大速度：duty比　0.8）
　startボタン：セーフティ・非常停止を解除
　selectボタン：非常停止
　〇ボタン：加速（1.5倍速）
　✕ボタン：減速（0.5倍速）
　L1ボタン：左旋回（通常速度：duty比 8/1.5）
　L2ボタン：右旋回（通常速度）
　左スティック：移動（通常速度）
　R2ボタン：旋回軸が右になる（右カーブ）
　L2ボタン：旋回軸が左になる（左カーブ）
